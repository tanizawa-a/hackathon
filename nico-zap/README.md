# ニコザップ（nico-zap）

動画を最大9本（2×2／3×2／3×3）同時に流し、盛り上がった枠を光らせ、見たいものへズームするデモ。
並べる動画は、ランキング、タグ検索の人気上位（オート）、自分で選んだ動画（マニュアル）の3通りから選べる。起動直後は「VOICEROIDキッチン」タグの人気上位を3×3で並べる（`src/config.ts` の `defaultMode`・`defaultTag`・`defaultGridLayout` で変更できる）。
設計は `../docs/plan.md` を参照。

## セットアップ

```bash
npm install
NODE_USE_ENV_PROXY=1 npm run fetch:videos   # オープンムービー（CC BY）をWikimedia Commonsから取得し、240pのモック動画・サムネイル・videos.jsonを生成
npm run gen:comments                        # コメントタイムラインと summaries.json を生成（シード固定）
NODE_USE_ENV_PROXY=1 npm run fetch:ranking  # スナップショット検索API v2 からジャンル別とタグ別の候補を取得し ranking.json に保存（ranking.mock.json も同時に生成）
npm run dev
```

- 上の3つのデータ生成は `NODE_USE_ENV_PROXY=1 npm run setup:data` でまとめて実行できる。
- ブラウザで `http://localhost:5173/` を開く。
- `NODE_USE_ENV_PROXY=1` は、プロキシ経由でしか外に出られない環境で必要。
- `fetch:videos` と `fetch:ranking`（サムネイルのモザイク生成）には ffmpeg が必要。
- オフラインで映像を用意する場合は `npm run gen:videos`（ffmpegのテストパターン）を使う。この場合 `videos.json` は作られず、クレジットは表示されない。
- APIに接続できない場合は `node scripts/fetch-ranking.ts --mock-only` でモック一覧だけを生成する。`ranking.json` が読めない場合は、自動で `ranking.mock.json` に切り替わる（`src/config.ts` の `dataSource` を `"mock"` にすると最初からモックを使う）。
- タグの一覧だけを取り直す場合は `node scripts/fetch-ranking.ts --tags-only` を使う。ジャンル別の候補は既存の `ranking.json` のまま残る。
- 映像を差し替える場合は、`scripts/fetch-videos.ts` の `FILMS` を編集して再実行する。ダウンロードした元動画は `.cache/source-videos/` に残る。
- 型チェックは `npm run typecheck`、ビルドは `npm run build`。

## 操作

| 操作 | 動作 |
| --- | --- |
| 「▶ 一斉に再生」 | すべての枠が同時に再生を始める（ミュート）。枠ごとに再生位置を少しずつずらす |
| 枠をクリック | ズーム（720p相当・1倍速・音あり・10秒巻き戻し）。他の枠は一時停止。生放送の枠は現在の放送位置から再生し、見ていない間の要約と山を表示する |
| Esc／「グリッドに戻る」 | グリッドに戻り、他の枠の再生を再開。ズーム中も進んでいた生放送の枠には、見ていない間の要約を数秒表示する |
| 枠 | 2×2／3×2／3×3 を切り替える。ランキング・タグは上位から並べ直し、マニュアルは並べた順のまま、あふれた分は待機に回る |
| 倍速 | スライダーで 0.5〜2倍（0.25刻み）。1.5倍以上はプレミアム会員限定で、横のボタンで プレミアム／一般会員 を切り替える（モック）。生放送の枠には効かない |
| 再生 | ハイライト（各山の15秒前から30秒）／頭から |
| 終了時 | 次を自動再生（待機中の動画と入れ替え。待機がなければ同じ動画を再生し直す）／消す |
| ランキング／タグ（オート）／マニュアル | 並べる動画の選び方を切り替える。マニュアルで並べた動画は、他のモードから戻っても残る |
| 指標 | 総合／再生数／コメント数／いいね数／マイリスト数で並べ替え（ランキング・タグ） |
| カテゴリ | ジャンルを複数選択して絞り込み（「すべて」は全ジャンル。ランキングのみ） |
| タグ | プリセットのタグを選ぶか入力する。その人気上位10本を並べる（タグのみ） |
| ＋ 動画を追加／空き枠をクリック | タイトル・タグで検索するか、動画ID・URLを貼り付けて追加。空き枠に入り、枠数を超えると待機に並ぶ（マニュアルのみ） |
| 枠の × | その動画を外す。外した枠には待機の先頭が繰り上がる（マニュアルのみ） |
| すべて外す | マニュアルで並べた動画と待機をすべて外す（マニュアルのみ） |
| サムネ | 実際のサムネイルを そのまま／モザイク／モック で表示（VOICEROIDキッチンの動画のみ） |
| デバッグ | 画質予算と各枠の画質を表示 |
| クレジット | 映像の出典とライセンスを表示 |

「再生」「終了時」「サムネ」「デバッグ」は、「▶ 一斉に再生」を押した後に表示される。

各枠には順位（マニュアルは追加順）、再生数、コメント数、再生位置、勢い（直近5秒のコメント数）のバーを表示する。盛り上がり区間に入った枠は光り、「盛り上がり中！」と表示する。

## 構成

| パス | 内容 |
| --- | --- |
| `src/config.ts` | しきい値、倍速、画質予算、生放送枠、指標・カテゴリ・プリセットタグ、データソース、初期表示 |
| `src/App.tsx` | 画面全体の状態（モード、枠、ズーム、生放送の見逃し区間） |
| `src/data/` | 一覧・コメント・要約・クレジットの読み込みと、表示用の動画データへの変換（`load.ts`）。データソースは `snapshotSource.ts`／`mockSource.ts` |
| `src/engine/excitement.ts` | 盛り上がり検知（秒ごとの件数 → 5秒移動平均 → 中央値の3倍かつ毎秒4件以上、20秒以内は統合）、ハイライト区間、直近コメント |
| `src/engine/ranking.ts` | 指標ごとのスコア、カテゴリ・タグ・除外リストによる絞り込み、マニュアル追加の検索、動画IDの抽出 |
| `src/engine/qualityBudget.ts` | 脇役の枠を360pから始め、画素数 × fps × 倍速 の合計が予算（90 Mpx/s）を超えたら、下位の枠から画質を1段ずつ下げる。ズーム中の主役（720p）は予算外 |
| `src/engine/queue.ts` | 位置固定の枠と待機キュー（追加・削除・終了時の入れ替え・枠数の変更） |
| `src/engine/liveClock.ts` | 生放送の擬似時計（停止中も進む）と未視聴区間、見ていない間の要約の順送り |
| `src/engine/summary.ts` | 再生位置より前にある直近の盛り上がりの要約を選ぶ |
| `src/components/` | Grid / Tile / ZoomView / CatchUpPanel / CommentStrip / ControlBar / SourceBar / AddVideoPanel / Credits |
| `scripts/` | 映像・コメント・一覧の取得と生成 |
| `public/data/blocklist.json` | デモに出さない動画の一覧 |

## ランキング

- 一覧は前日AM5:00時点のスナップショットで、公式ランキングとは一致しない。
- 「総合」は公式の計算式が非公開のため、再生数 + コメント数 + いいね数 × 5 + マイリスト数 × 15 の近似値で並べる。
- 候補プールは、直近7日に投稿された動画から、全ジャンルと各ジャンルについて4指標の上位を取得したもの。対象は `src/config.ts` の `CATEGORIES` に含まれるジャンルだけで、ショート動画（ss）は除く。
- `public/data/blocklist.json` に載せた動画は一覧に出さない。デモに向かないものを見つけたら、ここに追記する。
- タグ（オート）は、`PRESET_TAGS`（`src/config.ts` と `scripts/fetch-ranking.ts` の `TAGS`）のタグごとに、直近30日の4指標上位を事前に取得したもの。プリセット以外のタグを入力した場合は、取得済みの一覧からそのタグが付いた動画だけを探す。
- マニュアル追加の検索も、取得済みの一覧だけが対象。一覧にない動画IDを貼り付けた場合は、タイトルと数値なしで追加する。
- 次のタグが付いた動画は、取得の時点で除く：`DENY_TAGS`（`scripts/fetch-ranking.ts`）。
- ランキングモードだけ、4位と8位を生放送として扱う（`src/config.ts` の `liveMockIds` と `scripts/generate-comments.ts` の `LIVE_IDS`）。放送はデモ開始時点ですでに進んでいる扱いで、開始位置は `liveStartSeconds` で決める。

## 権利まわり

- 映像は Blender Foundation／Blender Studio のオープンムービー10本（CC BY 2.5／3.0／4.0）から切り出したもの。クレジットは画面上部の「クレジット」と、ズーム時の右下に表示する。出典・ライセンス・変更内容は `public/data/videos.json` にある。
- CC BY-SA の作品（Caminandes: Gran Dillama、Cosmos Laundromat）は、継承条件を避けるため使わない。
- 実際の動画のサムネイルは、`THUMBNAIL_TAGS`（`scripts/fetch-ranking.ts`。現在は「VOICEROIDキッチン」だけ）のタグの動画に限って取得し、`public/thumbnails/real/` に保存する。モザイクをかけた版を `public/thumbnails/mosaic/` に作る。上部の「サムネ」で そのまま／モザイク／モック を切り替える。これらは投稿者の作品なので、デモの場以外（録画の公開など）では使わない。どちらのディレクトリも `.gitignore` で除外している。
- それ以外の動画のサムネイルは、モック映像の1フレーム。
- 映像は、どの動画でもオープンムービー。
- コメントと要約は生成したモック。コメントは動画上に重ねず、ズーム時に枠外の帯にだけ表示する。

## その他

- 映像は10本しかないため、11本目以降の動画には同じ映像を順に割り当てる。
- 動画ファイルは240pだけを用意している。画質の切り替え（240p／360p／720p）は表示と予算計算だけのモック。
