# Zap Stack

YouTube 視聴中のページに、気になった動画を積み上げて同時再生する Chrome 拡張機能（プロトタイプ）。
設計は `../docs/pip-stack-extension-plan.md` を参照。

## 用語

- **スタック**：ページの上に浮かぶパネル全体。ここに動画を積んでいく。
- **タイル**：スタックの中の、動画1本ぶんの枠。

## インストール

1. `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする。
2. 「パッケージ化されていない拡張機能を読み込む」でこの `zap-stack/` ディレクトリを選ぶ。
3. コードを変更したら、拡張機能カードの更新ボタンを押してから YouTube タブを再読み込みする。

## 使い方

| 操作 | 動作 |
|---|---|
| 動画リンクを右クリック →「Zap Stack に追加」 | スタックにタイルを追加（同じ動画は追加しない、最大4枚）。追加すると音ありで自動再生する |
| 動画のリンク（サムネイル・タイトル）をスタックにドラッグ＆ドロップ | スタックにタイルを追加。リンクをドラッグし始めるとスタックが受け皿として表示される（タイルが0枚でも） |
| 動画ページの余白を右クリック →「この動画を Zap Stack に追加」 | 視聴中の動画をスタックに追加 |
| タイルをクリック | ズーム。そのタイルだけ音を出し（音量 100% までフェードイン）、他のタイルはミュートで再生を続ける。一時停止中のタイルをズームすると再生を再開する |
| 広告中のタイル | 「広告中」バッジを表示し、少し暗くする。ズームはできず、クリックはプレイヤーに届く（スキップボタンを押せる） |
| ズーム中の操作バー | 10秒戻す・一時停止／再生・10秒送る・次の動画・シークバー・再生時間。タイルの映像とタイトルのあいだに表示する |
| ズーム中のキー操作 | K / Space：一時停止／再生、J / L：10秒戻す／送る、← / →：5秒戻す／送る、Shift+N：次の動画 |
| ズーム中のタイルをクリック / 「戻る」 / Esc | グリッドに戻る。全タイルの音を戻す |
| タイルのタイトル横の ⏭ | 興味のない動画を飛ばして、次の関連動画（YouTube の自動再生と同じもの）に進む |
| タイルの × | そのタイルを削除 |
| ヘッダーの ⏸ / ▶ | すべてのタイルを一時停止／再生再開 |
| ヘッダーの 1x / 1.5x / 2x | 全タイルの再生速度を変更 |
| ヘッダーの － / ＋ | スタックの折りたたみ・展開 |
| ヘッダーの □ / ❐ | スタックの最大化・元に戻す（Esc でも戻る。ズーム中は先にズームが解ける）。最大化中は画面いっぱいにタイルを並べ、移動と大きさ変更はできない。折りたたみと最大化は同時にはならない |
| ヘッダーの ×（右端） | すべてのタイルを閉じる |
| ヘッダーをドラッグ | スタックを移動。画面の端から 48px 以内に置くとその端にくっつき、ズーム時は端から離れる向きに広がる。どの端にも近くないときは、中心を保ったまま四方に広がる |
| スタックの角のハンドルをドラッグ | ハンドルは四隅にあり、見た目には表示しない（カーソルを乗せると形が変わる）。ドラッグした角の反対の角を固定したまま、スタックの幅を変更（最小 280px。高さは 16:9 に合わせて決まる）。グリッド時とズーム時で別々に覚える。ダブルクリックで元の幅に戻す |

スタックの初期位置は画面の左下（動画ページ右側の関連動画の列と重ならないように）。

枚数に応じたレイアウト：1枚は1列、2〜4枚は2×2。ズーム中は主役が上段いっぱいに広がり、残りは下に1列で並ぶ。最大化中にズームすると、主役が画面の大部分を使い、残りは下の細い段に並ぶ。

## ファイル構成

```
zap-stack/
├── manifest.json
├── background.js   # 右クリックメニューの登録、タブへの送信
├── content.js      # スタックとタイル（iframe）の管理、再生・音量・画質の制御、ズーム、操作バー、
│                   # キー操作、ドラッグ＆ドロップ、スタックの移動・大きさ変更・最大化
├── content.css     # スタック・タイル・操作バーのスタイル
├── video-id.js     # URL から動画IDを取り出す（background.js と content.js で共有）
└── frame-main.js   # タイルの iframe 内（MAIN world）で画質を切り替える
```

## 実装メモ

- タイルは youtube.com の通常の動画ページ（`/watch?v={videoId}`）を同一オリジンの iframe で読み込む。
  - 埋め込みプレイヤー（`/embed`）は youtube.com 上でエラー 152-4 になり、埋め込みプレイヤーの自動再生ルール（同時に1本まで）も受けるため使わない。
  - 動画ページは `X-Frame-Options: SAMEORIGIN` なので、youtube.com 上からなら iframe に入れられる。
- iframe の中に CSS を入れて `#movie_player` だけを全面に表示する。広告中（`#movie_player.ad-showing`）はスキップボタンなどのため操作 UI を残す。
- 負荷を下げるため、iframe 内のコメント・おすすめ・説明欄（`#below` / `#secondary` など）を `display: none` にする。
- 画質はタイルでは 360p（`medium`）、最大化中は 480p（`large`）、ズーム中は最大 1080p（`hd1080`）にする。
  - プレイヤーの `setPlaybackQualityRange` は非公開の関数で、isolated world の content.js からは呼べない。content.js が iframe の `<html>` に `data-zap-stack-quality="low"|"mid"|"high"` を付け、MAIN world で動く frame-main.js がそれを読んで画質を当てる。
  - 画質の変更のたびにプレイヤーが読み込み直すため、同じ動画・同じ画質には当て直さない。広告中は当てない。
- 再生の制御は iframe の中の `<video>` を直接操作する（`play()` / `pause()` / `muted` / `playbackRate`）。
  - YouTube のプレイヤーは自分でミュートや速度を変えることがあるため、500ms ごとと `play` / `volumechange` / `ratechange` イベントのたびに、望む状態を当て直す。
  - 広告中は YouTube が 1 倍速に固定するため、速度は広告が終わってから当てる。
- 音量は、エラーになっていないタイルが2枚以上あるときは各 50%、1枚だけ（またはズーム中の主役）は 100%。一時停止中のタイルも枚数に数える。音が大きくなる方向の変化は 0.8 秒かけてフェードインし、小さくなる方向はすぐに反映する。
- タイルは音ありで再生する。Chrome に音ありの再生を止められた（`NotAllowedError`）ときは、ミュートで再生しておき、ページ上の次のクリックかキー入力で音を戻す。
- ズームのときは、ページ本体の動画を一時停止する。
- 一時停止はタイルごとに持つ（ヘッダーの一括操作も、各タイルの状態をまとめて変えるだけ）。一時停止中のタイルには中央に ⏸ マークを出す。
- 次の関連動画へのスキップは、iframe 内のプレイヤーの「次へ」ボタン（`.ytp-next-button`、見た目は CSS で隠している）をクリックして行う。
- ズーム中のキー操作は window の capture フェーズで受け取り、ページ本体のプレイヤーには届かないようにする。
- 再生できない動画は、プレイヤーのエラー表示（`.ytp-error`）を検知してエラー表示に切り替える。20 秒以内に `<video>` が見つからない場合も同様。
- 各タイルの映像の下に、動画のタイトルを1行で表示する（映像には重ねない）。タイトルは iframe 内の `document.title` から取る。
- 動画が終わると、YouTube の自動再生で関連動画に進む（意図した動作）。タイルのタイトルと、重複追加の判定に使う動画IDは、いま再生中の動画に追従する。
- 読み込み中は iframe を隠して、サムネイル（`i.ytimg.com`）を表示する。
- タイルを削除するときは、iframe を `about:blank` にしてから外し、再生をすぐ止める。
- 拡張機能の読み込み前から開いていたタブでは、初回の右クリック時に content script を注入する（`scripting` 権限）。

## 検証チェックリスト

- [ ] `/watch` の iframe が表示され、プレイヤーだけが全面に出る
- [ ] 追加したタイルが音ありで自動再生される（4枚同時）
- [ ] ズームすると、そのタイルだけ音が出て、他はミュートで再生を続ける
- [ ] 戻るで全タイルの音が戻る
- [ ] 複数のタイルが鳴っているときは各 50% の音量で、ズームすると主役がフェードインで 100% になる
- [ ] サムネイルやタイトルをスタックにドラッグ＆ドロップして追加できる（タイルが0枚のときも）
- [ ] ⏭ で次の関連動画に進み、タイトルが切り替わる
- [ ] ズーム中に操作バーとキー操作で、戻し・送り・一時停止・シークができる
- [ ] ヘッダーの ⏸ / ▶ で全タイルが止まる／再開する
- [ ] スタックが最初は左下に出る
- [ ] 最大化で画面いっぱいに広がり、元に戻すと前の位置と大きさに戻る
- [ ] 倍速切替が全タイルに効き、YouTube 側に戻されない
- [ ] 広告中にバッジが出て、ズームできず、スキップボタンを押せる
- [ ] YouTube 内で別の動画・検索結果に遷移してもスタックが残る
- [ ] 再生できない動画（非公開・年齢制限など）でエラー表示になる
- [ ] タイルは 360p、最大化中は 480p、ズームすると高画質になる（右クリック →「詳細統計情報」で確認）
- [ ] タイルの下にタイトルが出て、関連動画に進むと切り替わる
- [ ] 4枚同時でもページが重くなりすぎない
